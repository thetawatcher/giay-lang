# Quyết định

Mỗi quyết định về chính triết lý (thêm, bỏ, sửa một nguyên tắc; đổi ranh giới với repo sản phẩm; đổi cách phát hành) là một file `NNN-<slug>.md` với các mục: trạng thái và ngày, Quyết định, Vì sao, Không chọn, Hệ quả. Viết quyết định trước, rồi mới sửa `principles.md`, `rubric.yaml`, hay `adopting.md` trong cùng pull request. Quyết định riêng của một sản phẩm ghi ở repo của sản phẩm đó.

| Số | Quyết định |
| --- | --- |
| [001](001-repo-rieng.md) | Giấy lặng thành repo riêng, có version |
| [002](002-tieu-chi-giu-khung-va-mau.md) | Tiêu chí giữ khung, vạch kẻ và màu nhấn |
| [003](003-ra-bat-dau-tu-hieu-man.md) | Rà một màn bắt đầu từ hiểu màn và phương án bố cục |
