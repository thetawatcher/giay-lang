# Bảng rà Giấy lặng

<!-- Dùng mỗi khi đề xuất hay sửa một thiết kế giao diện. Rà đi ba bước, đúng thứ tự: hiểu màn, đưa phương án, rồi chạy bảng bảy nguyên tắc trên phương án được chọn. Bảng là bước kiểm, không phải chỗ nghĩ ra phương án. Mỗi dòng của bảng là một nguyên tắc trong rubric.yaml, đúng thứ tự. Đối chiếu bản đề xuất với hình ảnh gốc và nguyên tắc ở principles.md. -->

**Hiểu màn**

| Câu hỏi | Trả lời |
| --- | --- |
| Ai mở màn, lúc nào, trên thiết bị gì | |
| Câu hỏi đầu tiên họ cần màn trả lời | |
| Việc chính của màn | |
| Dữ liệu thật: bao nhiêu mục, mục dài nhất, lúc rỗng | |

- Trả lời bằng chuyện thật của người dùng và số liệu thật của màn, không bằng câu chung như "người dùng xem thông tin".

**Phương án**

| Phương án | Thứ tự khối | Hiện sẵn | Sau một lần bấm | Chọn |
| --- | --- | --- | --- | --- |
| A | | | | |
| B | | | | |

- Hai hoặc ba phương án, khác nhau về bố cục: thứ tự khối, cách nhóm, cái gì hiện sẵn. Khác nhau chỉ ở màu hay chữ thì chưa phải hai phương án.
- Mỗi phương án vẽ với dữ liệu thật, cả lúc nhiều và lúc rỗng. Phương án nào trả lời câu hỏi đầu tiên nhanh nhất thì nói ra.
- Người duyệt chọn; cột Chọn ghi phương án được chọn và vì sao.

**Bảy nguyên tắc**, chạy trên phương án được chọn

| Nguyên tắc | Đạt | Chưa đạt | Sửa đề xuất |
| --- | --- | --- | --- |
| Chữ dẫn, khung lùi | | | |
| Một màu nhấn, dùng tiết kiệm | | | |
| Mỗi màn một việc | | | |
| Im lặng mặc định | | | |
| Chữ ngắn | | | |
| Chuyển động nhỏ | | | |
| Mọi giá trị đi qua token | | | |

- **Đạt:** chỗ nào trên bản đề xuất cho thấy nguyên tắc được giữ.
- **Chưa đạt:** chỗ nào lệch, cụ thể tới phần tử. Thừa và bớt quá tay đều là lệch.
- **Sửa đề xuất:** một sửa cho mỗi chỗ lệch. Sửa bỏ một thứ thì nói câu hỏi đầu tiên và việc chính của màn còn được trả lời ra sao. Trên mẫu bấm thử, mỗi sửa nên bật/tắt được để người xem so trước và sau.
